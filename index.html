Open this page on a phone

The QR code is drawn by qrcode.js in this folder — it is made in your browser, no QR web service is asked for anything. It encodes the address printed above it, and nothing else.

What this page loads, and where your photo goes

  • leaf_model.onnx and model_info.json — from this same GitHub Pages address, your own repository.
  • onnxruntime-web — the JavaScript library that runs ONNX files, from the jsDelivr CDN. It also fetches its WebAssembly engine (ort-wasm-simd-threaded.wasm, about 15 MB, cached after the first visit) from there.
  • qrcode.js — a local file of this repository, for the QR code above.

The frame is read into a canvas on the phone and turned into numbers there. Those numbers go to the WebAssembly engine, which lives in the same tab. No photograph is sent anywhere — there is no upload call in this file: the browser's network tab shows only the files listed above (plus the tab icon the browser asks for itself), every one of them a download. Checked in a desktop browser: 10 responses, none of them a request carrying picture data.
